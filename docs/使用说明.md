## 1. 社员端（学员看到的）

### 1.1 登录

打开 `http://clab.foliagepeer.cn/`，输入学号 + 密码。

- 密码错了会提示「学号或密码错误」，**不会区分**是你学号打错还是密码打错（这是有意的，防止别人试探学号是否存在）
- 页面底部写着「初始密码为学号后六位，登录后可在报告最后一页修改」
- 连续输错 5 次会锁 10 分钟（同一个人），提示「错误次数过多，请 X 分钟后再试」
- **已经登录过的话**，再次打开会直接进报告页，不用重新登录（登录状态保留 7 天）

### 1.2 报告页怎么翻

进报告后是 **7 屏**，**手指上下滑**翻页（电脑上可以用滚轮/拖拽）：

1. 开场页 —— 姓名 + 部门 + 「上滑继续」
2. 加入天数 —— 大数字从 0 滚到你的天数
3. 志愿时长 —— 同上（小数会保留 1 位）
4. 活动次数
5. 年度伙伴
6. 部长寄语（保留换行排版）
7. 结尾 —— 有「修改密码」和「退出登录」两个按钮

每屏的文字有淡入/上浮动画，**每次滑回该屏动画会重播**；右侧小圆点是页码，可以直接点着跳。

### 1.3 背景音乐开关

**如果管理员给这位学员配了音乐**，报告页**右上角**会出现一个圆形按钮：

- 有呼吸动画 = 正在播放
- 上面有一道斜杠 = 暂停（**手机浏览器常会拦截自动播放**，点一下就开始，这是浏览器的限制不是故障）
- 自己关掉之后，下次登录不会再自动响（选择记在这台手机上）
- 退出登录会停止播放

### 1.4 修改密码

结尾页 →「修改密码」→ 填当前密码 + 新密码（6–64 位，不能和当前密码相同）+ 再输一次。

改完之后**其他设备上的登录会立刻失效**（当前这台不受影响）。忘记密码的话只能找管理员重置。

### 1.5 社员常见问题

| 现象 | 原因 / 怎么办 |
|---|---|
| 听不到声音 | 先看右上角按钮：有斜杠就点一下；再看看手机媒体音量；还是没有就说明只配了静音测试音或没配音乐 |
| 背景是纯色/渐变，没有照片 | 该学员（或所有人）还没配背景图，页面用自带的深色渐变兜底；管理员可在媒体页上传 |
| 登录不上，提示网络连接失败 | 换 WiFi／换浏览器再试；现在版本遇到这类网络中断会自动重试一次 |
| 想看别人的报告 | 不行，一个账号只能看到自己的 |

## 2. 管理端（管理员用的）

### 2.1 登录与退出

`http://clab.foliagepeer.cn/admin` → 输入管理员用户名密码。

- 登录状态保留 **12 小时**（比社员的 7 天短）
- 右上角「退出」**只退管理面板**，不影响同一浏览器里的社员登录
- 连续输错 5 次会锁 15 分钟
- 顶部如果有黄色横幅提示「容器对静态资源目录没有写权限」或「前后端版本不一致」，说明部署有问题，找负责人

### 2.2 三个页签

| 页签 | 做什么 |
|---|---|
| **成员** | 找人、改人、加人删人、勾选后批量操作、导出所选 |
| **媒体资源** | 给学员配背景图与背景音乐、批量上传文件 |
| **导入导出** | 粘贴文本批量添加、Excel 导入、导出名单、下载模板 |

### 2.3 成员页：找人、看状态

- **搜索**：输入学号或姓名的一部分即可（实时过滤）
- 每行显示：`姓名（学号）` + 部门、加入天数、志愿时长、活动次数
- 关键信息用蓝色小标签标出：`专属图目录：xxx`、`音乐：xxx`（表示这个学员被单独指定过）
- 行内四个按钮：**编辑** / **媒体**（跳到媒体页并选中他）/ **预览**（看他会看到什么）/ **删除**
- 「预览」很有用：它会列出该学员**实际会加载的** 7 张背景图和音乐（含从哪个位置找到的），排查「图传了没生效」时先看这里

### 2.4 新增 / 编辑 / 删除单个成员

**新增**：工具栏「新增成员」→ 填学号、姓名（必填），其他可留空 → 保存。

- 密码留空 = 用**学号后六位**作初始密码（提示会告诉你）
- 用这个初始密码去社员端登录一次，能验证链路通了

**编辑**：行内「编辑」→ 改哪些填哪些（**只有你改过的字段会被提交**，没动的不会被覆盖）。

- 学号是灰色的（不可改）：它是主键，改学号等于删旧建新
- 「新密码」留空 = 不改密码；填了 = 重设，并让该学员在其他设备上下线
- 「背景图目录」留空 = 用学号当目录；「背景音乐」留空 = 找与学号同名的音频

**删除**：行内「删除」→ 红色确认框（会告诉你后果）→ 删除。**删错了可以在随后的提示上点「撤销」**（10 秒内），连原密码一起还原。

### 2.5 勾选后的批量操作

每行前面有勾选框，工具栏有「全选」。**选择会跨搜索保留** —— 可以先搜「2021」勾一批，再搜「2022」接着勾，最后一起处理。勾选后出现蓝色操作条：

| 按钮 | 作用 |
|---|---|
| **批量修改** | 把某个字段统一改成新值（见 2.6） |
| **批量媒体** | 批量配图/配音乐（见 2.7） |
| **导出所选** | 只把这几位导出成 Excel（文件名带人数） |
| **重置密码** | 全部重置为「学号后六位」，并强制他们其他设备下线 |
| **批量删除** | 删除并清理登录状态 |
| **取消选择** | 清空勾选 |

### 2.6 批量修改某字段

「批量修改」→ 选字段（部门 / 加入天数 / 志愿时长 / 活动次数 / 年度伙伴 / 部长寄语 / 背景图目录 / 背景音乐）→ 填新值 → 应用。

- **留空表示清空该字段**（清空背景图目录/音乐 = 回到「用学号」的默认规则）
- 数字字段要填数字，否则会提示
- 姓名和学号**不能**批量改（学号是主键，姓名批量改几乎必然是误操作），密码也不能批量设同一个值，只能走「重置密码」
- 改错了：10 秒内在提示上点「撤销」，字段回到改前的值

### 2.7 批量媒体操作

「批量媒体」→ 四选一：

| 操作 | 说明 |
|---|---|
| **指派背景音乐** | 从音乐库选一首；选第一项「（清空，回到与学号同名）」= 取消指定 |
| **设置背景图目录** | 填目录名（如 `shared-theme`）；**留空 = 回到各自的学号目录** |
| **上传专属背景图** | 选槽位 + 选图 → **同一张图写进每人各自的目录**（同名覆盖） |
| **删除专属背景图** | 选槽位 → 删掉这些人该槽位的专属图，他们回落到共享图；没有的会自动跳过 |

上传和删除是逐个学员执行并显示进度的。

### 2.8 导入导出

**粘贴文本批量添加 / 更新**（最常用）

每行一名学员，字段顺序与 Excel 列一致：

```
学号,密码,姓名,部门,加入天数,志愿时长,活动次数,年度伙伴,部长寄语,背景图目录,背景音乐
2099001,init123456,王小明,外联部,120,60,8,李四,继续加油,,
2099002,,张小美,宣传部,90,40,5,王五,未来可期,,
```

- 逗号或 Tab 分隔（全角逗号也行），**字段里有逗号就用双引号包起来**
- 空行、`#` 开头的行会忽略；一行就是单条，多行就是多条
- 粘贴后先点「预览」：逐行标出 **新增 / 更新 / 无变化 / 错误**，并说明改动了哪些字段、密码怎么处理
- 确认无误再点「确认导入」（**改动过内容就必须重新预览**，防止预览与提交的不是同一份）

**Excel 导入**：选文件 → 预览 → 确认导入。模板可以点「下载导入模板」下载。

**密码列的三种规则**（文本和 Excel 一致）：

| 密码列 | 结果 |
|---|---|
| 填了值 | 用该值（可用于重置某人密码） |
| 留空 + 学员已存在 | **保留原密码不变**（只改其他字段时用这个） |
| 留空 + 新学员 | 用**学号后六位**作初始密码，导入结束会告诉你有多少人用了初始密码 |

**导出**：「下载全部成员 Excel」导出所有人；只要部分人就在成员页勾选后点「导出所选」。

- 导出文件的**密码列必然是空的**（库里只有哈希，导不出明文）
- 改完这份 Excel 再导回来即可：老学员保留原密码，新学员用学号后六位
- 一次最多处理 5000 行 / 500 人

### 2.9 媒体资源页：配背景图与音乐

顶部下拉选学员，下面三块：

**① 该学员的专属背景图**（7 个槽位）

每个槽位显示当前生效的文件；「上传」选图（同名可替换）、「删除」去掉（回落到共享图）。同一槽位如果放了多种格式，会提示哪些「未生效」（格式优先级：jpg → jpeg → png → webp）。

**② 共享背景图**（同样 7 个槽位）

放这里的图**所有学员**都会用。专属图同槽位会覆盖共享图。

7 个槽位名与屏幕的对应：

| 槽位名 | 对应屏 |
|---|---|
| `01-opening` | 开场（姓名+部门） |
| `02-days` | 加入天数 |
| `03-hours` | 志愿时长 |
| `04-activities` | 活动次数 |
| `05-partner` | 年度伙伴 |
| `06-message` | 部长寄语 |
| `07-ending` | 结尾 |

**③ 背景音乐**

「选择音频文件」+「上传音乐」→ 会问你存成什么文件名（默认建议 `<学号>.<后缀>`，**用学号命名就会自动归属该学员**）。列表里每条都能**试听**、看「被谁使用」、**设为当前选中学员的音乐**、删除。

- 支持 mp3 / m4a / ogg / wav；多个格式同名时按这个顺序取第一个
- 图片单张上限 5MB，音乐 8MB
- 文件一放上去就生效，**不需要重启任何东西**；换图后社员那边会自动看到新图（URL 带版本号，绕开浏览器缓存）

### 2.10 批量上传（按文件名自动归属）

在媒体页底部，可以**一次选多个文件**或**整个文件夹**。上传前会先列出每份文件的归属清单，确认后再传。

| 文件名 / 目录结构 | 会给谁 | 落到哪 |
|---|---|---|
| `01-opening.jpg` | 所有学员（共享图） | `images/01-opening.jpg` |
| `2021001-01-opening.jpg` 或 `2021001_01-opening.jpg` | 只有 2021001 | `images/2021001/01-opening.jpg` |
| 文件夹里的 `2021001/01-opening.jpg` | 只有 2021001 | 同上 |
| `2021001.mp3` | 2021001 的背景音乐 | `music/2021001.mp3` |

- 文件名无法识别、学号不在成员表里、超过大小上限的，会在清单里**标红拦下**
- 同名文件默认跳过并说明；勾选「同名文件直接覆盖」再传一次即可
- 整个过程**不改成员数据**，只是把文件放到正确位置

### 2.11 提示、确认与撤销（交互约定）

- **成功/信息** → 屏幕下方（电脑上右下角）的**轻提示**，4.5 秒自动消失，不打断你
- **错误/参数校验** → 必须点确认的**对话框**（这类信息需要你看清）
- **危险操作**（删除成员、批量删除、删除文件…）→ 红色确认按钮，标题写明要做什么
- **带撤销的提示**停留 **10 秒**，上面有「撤销」按钮；提示**本身不响应点击**（防误触），要关只能点右侧的小叉
- **能撤销的**：删除成员、批量删除、批量修改字段、批量重置密码、批量媒体指派、单条编辑保存 —— **撤销会把原密码一起还原**
- **不能撤销的**：媒体文件的删除（图片/音乐文件没留底，确认框里已注明）

## 5. 已知边界与注意事项

1. **当前背景图是占位图**（两张纯色小图），不是真实素材；音乐是 8 秒测试音，都不是最终效果
2. **iOS 自动播放最严**：iPhone 上音乐基本都要手动点一下（这是系统策略，改不了）
3. **媒体文件删除不可撤销**（没留底）；成员数据删除可撤销（10 秒窗口、服务端 15 分钟内有效）
4. **撤销令牌最多保留最近 20 次改动**，重启容器即清空
5. **HTTPS 尚未启用**：现在是 HTTP，浏览器可能提示「不安全」——校内使用先这样，后续会配证书
6. 面板的批量导入、批量操作上限：**一次 500 人 / 5000 行**；成员列表一次返回最多 200 条（搜索可以缩小范围）
7. 这台机器靠校园网直连提供访问，没有公网入口 —— 校内能开，出了校园网就访问不到
8. **反馈请带上**：手机型号 + 浏览器 + 你点了什么 + 看到什么（截图最好）。出问题的时刻、提示原文越具体越好排查
